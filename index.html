Le projet

J'utilise l'intelligence artificielle pour développer et affiner, morceau après morceau, un moteur qui transcrit la musique en notes.

Les essais se font sur des musiques elles-mêmes créées par IA, avec ElevenLabs Music.

À terme : un éditeur de partitions gratuit, puis un générateur d'accompagnements pour jouer avec.

Vous jouez ? Devenez contributeur : corrigez, notez, proposez.

Le code est ouvert sur GitHub, la plateforme où les développeurs publient leur code en libre accès, pour que chacun puisse le voir, le tester et l'améliorer.
